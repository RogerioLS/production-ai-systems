# Project 01: LLM Basics

This project focuses on the fundamental building blocks of Large Language Models.

## Learning Objectives
- Understand Tokenization (Byte-Pair Encoding).
- Explore Embedding spaces.
- Deconstruct the Attention Mechanism.
- Manage Context Windows and Costs.

## Structure
- `src/`: Core logic for token estimation and model interaction.
- `notebooks/`: Visual experiments and learning notes.
- `tests/`: Validation of token counts and output formats.
